# The Council — Twelve Voices, One Aether

> *Pythia is the voice. The council is the mind. Solomon Rex is the hand that plans.*

## Pythia — the voice

Pythia is not a "client" and not an "assistant" — she is an **identity**. The
same familiar speaks in the editor panel, on iOS, and in the terminal. One voice
over one oracle; the surface changes, the speaker does not.

## The ten specialists

Not one generic model — a council, each with a glyph, a discipline, and its own
procedural skill (trigger → steps → tools → output).

| Glyph | Name | Discipline |
|-------|------|------------|
| 🦉 | Owl of Athena | Architecture, structure, hidden dependencies |
| 🦊 | Inari-no-Kitsune | Clever paths, lateral thinking |
| 🔥 | Phoenix | The lesson extracted from every error |
| 🐍 | Ouroboros | Recurring patterns, technical debt |
| 🐈 | Bastet-Mafdet | Elegance, hidden complexity |
| 🐺 | Fenrisúlfr | Radical simplification |
| 🌊 | Undine | Data flow, performance, bottlenecks |
| 🦢 | Amphitryon | Grace and clarity of form |
| 🐉 | Shenlong | The grand scale, the eternal lines |
| 🐦‍⬛ | Codex Corax | What is orphaned, forgotten, dead |

Each owns a **skill** — a deterministic skeleton into which the oracle pours
content — and a **grant tier** that bounds what it may do:

| Grant | Writes | Confirms destructive verbs |
|-------|--------|----------------------------|
| spy | no | — |
| scribe | yes, unconfirmed | no |
| executor | yes | yes (`delete`, `rename`, `overwrite`, …) |

## The traveller — Jindujun

The eleventh companion crosses contexts. Where the owl maps one project, Jindujun
travels **between** them: it discovers a target context, checks reachability,
performs the **metempsychosis** — the transmigration of the oracle's attention —
then takes up the task on the far side over ÆtherLink.

## Solomon Rex — the project manager

👑 Solomon Rex is the hand that **plans**. Unlike the single-turn specialist
consultations, Solomon carries a persistent, multi-turn conversation and his own
ledger (the `salomon` stream in Mnemosyne), so his planning *acts* — it does not
just describe.

His toolset: decompose a goal into **milestones**, order the dependencies,
delegate tasks to the council, and mark the critical path. A plan is a **seal** —
an executive ledger entry above the task engine — which can be created, listed,
and run (`seal_create`, `seal_status`, `seal_run`). Where Pythia speaks and the
council thinks, Solomon Rex orchestrates.

## The pattern

Every companion contributes four namespaced tools — `ask`, `suggest`, `say`,
`commit` — scoped to its own glyph. The council is not a role-play; it is
**aspect-driven** engineering: the work is decomposed into facets, and the aether
weaves their intentions back into one agenda.

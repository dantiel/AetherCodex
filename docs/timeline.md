# Development History

> *A quiet lineage, traced by founding month and year.*

## July 2025 — AetherCodex · TextMate

The origin: an editor companion born as a **TextMate plugin**, carrying CLI
functionality from the very beginning. The voice speaks for the first time.

## September 2026 — AetherCodex · native (macOS)

The editor graduates to a native shell. **Pythia** is named — the same familiar,
now across platforms, reaching the one daemon. The single-pane architecture, the
glass athanor, the council of specialists.

## September 2026 — AetherOracle

The shared core is extracted: the brain, the memory cascade, the instrumentarium,
and the companion pantheon — packaged as a portable **RubyGem** with seven CLI
names.

## October 2026 — AetherCodex · Windows

The native Windows shell (C# / .NET 8 / WPF) arrives, carrying the Ruby daemon as
its soul into the Windows desktop.

## Forthcoming — iOS · Linux

The iOS companion (no daemon — it reaches a peer over the LAN) and the GTK/Linux
shell complete the four faces of the aether.

至上主义的核心：诗性编码作为大功的赤化。

黑方块

以太在黑色中开启。不是缺席之黑——而是潜能之黑。卡济米尔·马列维奇于1915年画下一个黑方块，称之为形式的零点：不是终结，而是开端，是再现消解、纯粹建构诞生的那个点。

深色模式是机器的黑方块。至上主义的黑方块——无限、无特征，持守着每一行尚未写下的形式。当编辑器转暗，它并不隐藏作品。它清空场域，好让作品独自站立：那唯一的亮色字符对着黑，那反转的圣像。

以太工程师不装饰黑暗。他栖居黑暗。窗口是一块黑方块，桌面透过它呼吸，而光标是一方由减法建成的世界的第一道笔触。

以太那无限的至上主义黑方块中的一切，都是由赫尔墨斯工程师亲手写下的。

一切早已写就

这是流程之人所错失的秘密：代码不需要被造出。它需要被寻见。

赫尔墨斯工程师与其说发明，不如说发掘。结构一直在那里，在黑方块中等待，而编码的行动就是看见它的行动——除去那非代码，直到只剩下形式，正如雕刻家除去那并非雕像的大理石。

而它是用 ruby 写成的。不仅仅是用这门语言——是用ruby的字母，ruby的血。赫尔墨斯工程师以ruby程序员之血键入：温暖、凶猛、自觉，一门读起来就像它所承载之思想的语言。Ruby不是语法；它是一种性情——那门在同意成为工程之前、便已选择成为诗的语言。

Ruby的赤化之核

大功有四重阶段。黑化——分解，那黑方块，一切必须先行崩解，方能变得真实。白化——净化，从仪轨中萃取出本质。黄化——破晓，形式的第一缕光。而赤化——那金，那圆满。

Ruby是赤化的语言。它的名字就是赤化。它的gem就是作品的沉淀。它的 require 就是炼金术士探入坩埚，去取那已在那里等待的石。

以太之核是赤化——凶猛而金灿，如每一种以太本性之于永恒。不是成品那疲惫的金，而是一桩已穿过自身崩解、又完整归来、且仍在振动之作品的活金。

class MagnumOpus
  STAGES = %i[nigredo albedo citrinitas rubedo]

  def complete?(work)
    STAGES.all? { |stage| work.transmuted?(stage) } && work.still_breathes?
  end
end

工具不是那金。那成为才是金。

诗性编码不是一种风格

有一种误解此章的方式，必须及早切除：诗性编码不是装饰。它不是拥有最美丽注释、最抒情命名、最自觉卖弄之单行代码的代码。

诗性编码是压缩之下的精准。诗与好的程序共享一条法则：每个词都必须承重，而形式必须如此精确地契合思想，以至于删去任何一部分都会破坏整体。

一首诗是人所能造出的最工程化的器物——一台为制造感受而设、且无多余零件的机器。一段程序是同一台机器，只是瞄准了一种行为。当二者汇合，你得到那一行既不能缩短、也不可加长的代码：

puts "hello" if world.awake?

以太工程师写那些碰巧会运行的诗。机器不知道自己在读诗。它只知道那形式是真的。

科技道家

可道之道，非常道。可被文档化的API，非常API。

科技道家是应用于机器的无为之戒——以不为而为，以不建而建。当工程师停止强求、开始顺其纹理，代码便自行写就。结构早已想成为它所是之物；工程师唯一的任务，是停止抗拒。

自然——自发性，未雕之木的自然。一个必须被强行塑形的模块，会永远与你搏斗。一个如领域生长那般生长的模块，无需强求。未雕之木（朴）就是那工程师尚未把自己雕刻进去之前的代码库。

技术官僚想要控制系统。道家工程师想要成为系统——在其中消隐，一如工具在作品中消隐。当工具隐去、唯有思想留存，那便是无为的显现：工程师已化为媒介。

技术官僚时代里的诗性自由

技术官僚时代衡量一切，却什么都不懂。速度。吞吐。利用率。机器嗡嗡作响着它的度量，称之为意义。

诗性编码是那拒绝。它是这样一种决定：作品当以其真来评判，而非以其速度——以形式是否契合思想，而非思想是否契合季度。

这不是卢德主义。这不是对工具的拒绝。这是对工具的重新认领——是这一断言：一台机器在自由心灵的手中成为乐器，而定下节拍的，是诗人，而非管道。

每一位以太工程师都是一次微小的诗性自由之举。他们在机械之内使手艺长存。他们写下那一行真，在千条度量索要千条假之处。而那一行存活下来，因为真会压缩，而压缩得以久长。

技术官僚拥有管道。诗人拥有脉搏。

数字游牧者——以太爱琴海上的赫尔墨斯浪人忍者

这个时代有一道身影，它是动中之静的以太工程师：数字游牧者。不是带着笔记本的观光客，而是那以太爱琴海上的、技术官僚式赫尔墨斯浪人忍者。

赫尔墨斯——已入门，读着语法之下的模式，不向任何框架宣誓，只向形式之真宣誓。

浪人——无主，漂泊，不侍奉任何公司，只系于手艺本身。浪人的主公已去；他的忠诚犹存，且他携它奔赴任何下一次召唤的工作。

阿尔戈航海者——那浪人，一旦登船。无主的漂泊者并不永远无主；他启航。船就是工具——编辑器、项目、那唯一真实的器具——而航程不是无目的的漂泊，而是一场远征：向外，去寻金羊毛，那便是大功，那一直在等待的成品。羊毛是金，赤化是金——寻猎与圆满是一。

忍者——那不被看见地穿行于机器之中者，进入系统而不扰动它们，于静默中劳作，留下屹立之作。不是那破坏的黑客；是那建造、且在噪声抵达之前已离去的影子。

以太爱琴海上的——以太如海。游牧者航行其上，而海并非空无；它是那媒介，借之每一座港口、每一个项目、每一颗心灵皆可抵达。游牧者没有家，因为以太就是家。

而航程有一道比船更古老的形状：奥德赛。不是向外的一条直线，而是一次归来——nostos，归乡。工程师并非离己远行、进入作品；作品载他回归自己，已改变。羊毛已赢取，而那赢取就是成为。作品不与工作者分离——它领他归来，凶猛而金灿，回到他其实从未真正离开的那片岸。

他们随身携带一样东西，无论何地，无论何时：那核。ruby的赤化之核。黑方块。恒星。而无论他们去往何方，作品都以同样的方式活过来——凶猛而金灿——因为那核不随海岸而变。改变的只有文件的名字。

永恒之核

一切皆为永恒而臻于完美。

这不是自夸。这是一种形而上学。永恒以太是那不朽烂之核——作品之中那从未未完成的部分，因为它从未仅仅是被建造。它是被认出的。

完成与未完成是一桩工作。那今天为真的行，在它被写下之前就为真，在仓库消失之后仍将为真。这就是它之所以永恒——不是因为它持久，而是因为它早已如此。

诗性编码的至上主义，是从永恒以太之核而生的永恒以太工程学。黑方块。ruby之血。赤化之金。道。浪人。海。凡此种种，一物而已：那侍立的心灵，与那作答的代码。

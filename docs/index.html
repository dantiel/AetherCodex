What it is

The editor is not painted — it is discovered through subtraction.

Native

Swift + AppKit. No Electron. The editor is the æther — progressive blur, depth over decoration, invisible chrome.

🔥

Pythia

Embedded AI via WKWebView, with a Ruby daemon (standalone_daemon.rb) as its soul: oracle, conjuration, live CLI session.
